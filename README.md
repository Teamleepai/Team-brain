## LEAP OS Constitution

The `/constitution` directory holds the founding engineering playbook for LEAP OS — the AI operating system this repo is building toward. Start with [`constitution/MASTER_CONSTITUTION.md`](constitution/MASTER_CONSTITUTION.md); it links out to every companion standards document (product philosophy, engineering, security, AI agent design, memory architecture, coding, testing, observability, UX, deployment, continuous improvement, definition of done, and roadmap).
